# Video Compressor 2.0.0-beta.1

This prerelease starts the V2 interface redesign while retaining the existing FFmpeg compression engine.

- Redesigned the app with a dark layout, blue accent, navigation rail, and separate Compress, Settings, and About pages.
- Kept target-size presets and the Custom amount on Compress, with file details, progress, ETA, pass/attempt status, cancellation, and finished-file actions.
- Added searchable Settings for the output folder and supported formats.
- Uses a separate beta install identity, install folder, Start Menu entry, and settings folder. Stable v1.x installs and data remain separate.
- Automatic update checks are disabled in beta builds.

Download `VideoCompressorBetaSetup.exe` to install the beta alongside the stable app.
